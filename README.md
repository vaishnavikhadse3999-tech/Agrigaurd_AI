🌱 AgriGuard AI — Smart Farming Made Easy

AgriGuard AI is a smart farming web application designed to help farmers access useful information about crop health, weather, irrigation, and agricultural activities.

✨ Features

🌿 AI Crop Doctor — Analyze crop images to help identify potential diseases.

💬 AI Farming Assistant — Get farming guidance through an interactive chat interface.

🌦️ Weather — Access weather information for farming decisions.

💧 Water & Irrigation — Explore irrigation and water-management guidance.

📈 Market Price — Access agricultural market information.

⚠️ Disease Alert — View potential crop risks and disease guidance.

🌾 Organic Farming — Learn about organic farming practices.

🚜 Farm Work Planner — Organize farm activities.

🛠️ Technologies Used

React

TypeScript

Tailwind CSS

Vite

💻 Run Locally

Make sure Node.js is installed.

Clone the repository:

git clone https://github.com/vaishnavikhadse3999-tech/Agriguard_AI.git

Open the project folder:

cd Agriguard_AI

Install dependencies:

npm install

Start the development server:

npm run dev
